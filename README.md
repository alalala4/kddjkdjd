# РЕЙТ AI Bot - Telegram бот с OpenAI-совместимым API

Личный Telegram-бот с искусственным интеллектом через OpenAI или OpenAI-совместимый API.

## Что умеет

- **Умный чат** - отвечает на вопросы через выбранную модель
- **Поиск в интернете** - работает с OpenAI Responses API
- **Генерация картинок** - работает с OpenAI Images API
- **Память диалога** - помнит последние 20 сообщений
- **Только для вас** - доступ ограничен вашим Telegram ID

## Стоимость

**$0. Ноль. Бесплатно.**

- Google AI Studio API - бесплатно (лимит ~1500 запросов/день)
- Генерация картинок - бесплатно (до 500 картинок/день)
- Хостинг на Railway - бесплатно ($5 кредитов/мес, хватает)

# ИНСТРУКЦИЯ ДЛЯ НОВИЧКА (пошагово)

Если вы никогда не запускали ботов - не переживайте. Следуйте шагам ниже,

## Шаг 1: Создайте бота в Telegram (2 минуты)

1. Откройте Telegram
2. В поиске найдите **@BotFather** (с синей галочкой)
3. Напишите ему: `/newbot`
4. Он спросит имя бота - напишите любое, например: `Мой AI Помощник`
5. Он спросит username - придумайте уникальный, например: `reit_ai_helper_bot`
   (должен заканчиваться на `bot`)
6. BotFather ответит токеном - длинная строка типа:
   `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
7. **Скопируйте этот токен и сохраните** - он нам нужен

---

## Шаг 2: Получите API ключ (3 минуты)

Для обычного OpenAI: https://platform.openai.com/api-keys

Для OpenAI-совместимого провайдера сохраните также `base_url` из его инструкции.
Для freemodel.dev используйте OpenAI format: `OPENAI_BASE_URL=https://api.freemodel.dev/v1`.

---

## Шаг 3: Узнайте свой Telegram ID (1 минута)

1. В Telegram найдите бота **@userinfobot**
2. Напишите ему что угодно (например: "привет")
3. Он ответит вашим ID - число типа: `123456789`
4. **Запишите это число**

## Шаг 4: Запустите бота (выберите способ)

### Способ А: На своём компьютере (для теста)

Если хотите сначала проверить, что всё работает:

1. Установите Python 3.11+ (скачайте с https://python.org)
2. Скачайте файлы бота (bot.py, requirements.txt)
3. Откройте терминал (командную строку) в папке с ботом
4. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
5. Создайте файл `.env` (скопируйте из `.env.example`) и заполните:
   ```
   TELEGRAM_TOKEN=ваш_токен_от_BotFather
   OPENAI_API_KEY=ваш_API_ключ
   # если провайдер не OpenAI:
   OPENAI_BASE_URL=https://api.freemodel.dev/v1
   CHAT_MODEL=gpt-5.4-mini
   ENABLE_WEB_SEARCH=0
   ENABLE_IMAGE_GENERATION=0
   ALLOWED_USER_ID=ваш_telegram_id
   ```
6. Запустите:
   ```
   python bot.py
   ```
7. Откройте Telegram, найдите своего бота и напишите `/start`

**Минус:** бот работает только пока компьютер включён.

### Способ Б: На Railway (бесплатно, работает 24/7) - РЕКОМЕНДУЮ

Это облачный сервер. Бот будет работать круглосуточно, даже когда ваш компьютер выключен.

1. Зайдите на https://railway.app
2. Нажмите **"Login"** → войдите через **GitHub**
   (если нет GitHub - зарегистрируйтесь на https://github.com, это бесплатно)
3. На главной нажмите **"New Project"**
4. Выберите **"Deploy from GitHub repo"**
5. Подключите свой GitHub и выберите репозиторий с ботом
   (или выберите "Empty project" → "Add a service" → "GitHub repo")
6. Railway создаст сервис. Перейдите в **Settings** (настройки) сервиса:
   - Root Directory: оставьте пустым, файлы бота лежат в корне ветки
   - Start Command: `python bot.py`
7. Перейдите во вкладку **Variables** и добавьте переменные:
   ```
   TELEGRAM_TOKEN = ваш_токен_от_BotFather
   OPENAI_API_KEY = ваш_API_ключ
   ALLOWED_USER_ID = ваш_telegram_id

   # если ключ от OpenAI-совместимого провайдера:
   OPENAI_BASE_URL = https://api.freemodel.dev/v1
   CHAT_MODEL = gpt-5.4-mini
   ENABLE_WEB_SEARCH = 0
   ENABLE_IMAGE_GENERATION = 0
   ```
8. Нажмите **Deploy** - Railway установит зависимости и запустит бота
9. Подождите 1-2 минуты, откройте Telegram и напишите боту `/start`

**Готово! Бот работает 24/7 бесплатно.**

   - `TELEGRAM_TOKEN`
   - `OPENAI_API_KEY`
   - `ALLOWED_USER_ID`
7. Нажмите **Create Background Worker**

## Возможные проблемы

### Бот не отвечает
- Проверьте, что TELEGRAM_TOKEN правильный
- Проверьте логи на Railway (вкладка Logs)
- Убедитесь, что ALLOWED_USER_ID совпадает с вашим ID

### "Ошибка: quota exceeded"
- Вы превысили бесплатный лимит (1500 запросов/день)
- Подождите до завтра - лимит сбросится

### Картинки не генерируются
- Попробуйте другое описание (на английском часто лучше)
- Провайдер может отказать, если описание нарушает его правила
- Попробуйте добавить стиль: "в стиле фото", "в стиле иллюстрации"

### Railway показывает ошибку при деплое
- Убедитесь, что Root Directory пустой
- Проверьте, что все обязательные переменные заданы в Variables
- Посмотрите логи - там будет написано, что не так
